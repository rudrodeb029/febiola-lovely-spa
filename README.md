# Febiola Lovely Spa USA 🌿

> **Premier Luxury In-Home Spa & Wellness Sanctuary Across All 50 US States**

A standalone, luxury spa & wellness web application crafted with **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS v4**. Built for seamless in-home and studio reservations, client concierge communication, and full administrative management.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Access Admin Portal
- Visit [http://localhost:5173/#admin](http://localhost:5173/#admin) or click the **Admin Portal** link in the footer.

### 4. Build for Production
```bash
npm run build
```
The optimized static output will be created in the `dist/` directory, ready to deploy to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
